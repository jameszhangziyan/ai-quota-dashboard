额度登录设置

把浏览器里官方额度请求「复制为 cURL」粘贴到这里。内容只保存在这台 Mac 上，只会发回给原来的官方地址；这个页面只能在 Mac 本机打开。

WorkBuddy 未设置

  1. 在 Chrome 打开 https://www.workbuddy.cn/profile/plans-usage（未登录会先让你扫码登录），确认已登录、能看到用量数字。
  2. 按 ⌥⌘I（Option+Command+I）打开开发者工具，点顶部的 Network（网络） 标签。
  3. 开着开发者工具按 ⌘R 刷新页面（必须在打开 Network 之后刷新，否则列表是空的）。
  4. 在 Network 左上角的过滤框输入 get-user-resource，列表里会剩一条（同名多条任选一条）。
  5. 在这条上右键 → Copy（复制）→ Copy as cURL (bash)。注意别选 cmd / PowerShell 版本。
  6. 回到这里粘贴，点「保存并测试」。

Kimi 会员（含 Kimi Work） 未设置

  1. 在 Chrome 打开 https://www.kimi.com/settings/subscription（「我的订阅」页），确认已登录、能看到用量数字。
  2. 按 ⌥⌘I（Option+Command+I）打开开发者工具，点顶部的 Network（网络） 标签。
  3. 开着开发者工具按 ⌘R 刷新页面（必须在打开 Network 之后刷新，否则列表是空的）。
  4. 在 Network 左上角的过滤框输入 GetSubscriptionStats，列表里会剩一条（同名多条任选一条）。如果弹出「已取消自动续订」之类的提示，点「我知道了」关掉即可。
  5. 在这条上右键 → Copy（复制）→ Copy as cURL (bash)。注意别选 cmd / PowerShell 版本。
  6. 回到这里粘贴，点「保存并测试」。

Gemini 未设置

注意：这条请求里带着你完整的 Google 登录 Cookie（能登录 Gmail、云端硬盘等），只保存在这台 Mac 上，千万不要发给任何人。Google 会不定期更换 Cookie，届时需要重新粘贴。

  1. 在 Chrome 打开 https://gemini.google.com/usage，确认已登录、能看到用量。
  2. 按 ⌥⌘I（Option+Command+I）打开开发者工具，点顶部的 Network（网络） 标签。
  3. 开着开发者工具按 ⌘R 刷新页面。
  4. 在过滤框输入 usage，找 Type（类型）是 document、名字叫 usage 的那一条（一般是列表第一条）。
  5. 在这条上右键 → Copy（复制）→ Copy as cURL (bash)。
  6. 回到这里粘贴，点「保存并测试」。

网页登录过期后（一般几天到几周），看板会提示「请重新粘贴」，重复上面步骤即可。粘贴的内容相当于你的登录凭证，不要发给别人。
